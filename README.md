# Workset Phase 0 — Popup Validation

공용 PC에서 URL 하나로 클릭/엔터 한 번에 여러 웹앱을 새 탭으로 동시에 여는 방식이 실제 브라우저에서 팝업 차단 없이 동작하는지 검증하는 최소 실험용 페이지입니다.

- 배포 URL: https://myworkset.netlify.app/

## 테스트 방법

1. 위 URL을 순정 Chrome(시크릿 모드 아님, 확장 프로그램 없는 상태 권장)에서 엽니다.
2. `ENTER` 버튼을 클릭하거나, 페이지 로드 후 그 문서 위에서 키보드 엔터를 누릅니다.
   - 주소창에서 페이지로 이동할 때 눌렀던 엔터는 유효하지 않습니다. 반드시 페이지가 열린 뒤 새로 눌러야 합니다.
3. Claude / ChatGPT / Linear 3개 탭이 동시에 열리는지 확인합니다.
4. 화면에 표시되는 로그(✅ 열림 / ❌ 차단됨)를 확인하고, 차단된 항목은 옆에 뜨는 링크로 수동으로 열어봅니다.
